# Reference-model measurements

Crawler performance results use
[`reference-measurement-protocol-v1.md`](reference-measurement-protocol-v1.md)
and the machine-readable
[`measurement-record-v1.schema.json`](measurement-record-v1.schema.json).

This directory defines how to collect and report measurements; it does not
claim that a benchmark has been run. Result records should be added only from
an actual run with raw samples and the required revision/device/provenance
fields. Fixture geometry and licensing live in `fixtures/reference-models/`.
